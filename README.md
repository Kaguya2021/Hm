# Render Ping Bot 🚀

Легкий и надежный Telegram-бот на Node.js и grammY для мониторинга доступности сайтов и поддержания их активности на Render.

## Требования
- Node.js LTS (версия 18+)
- База данных PostgreSQL (например, Neon)
- Токен Telegram-бота от @BotFather
